Eclipse: Sistema Otorrinolaringología

OtorrinolaringologíaSistema Visual para ORLUnidad de ORLInteracoustics

Eclipse de Interacoustics es una plataforma integral y modular para otorrinolaringología, diseñada para cubrir de forma precisa y eficiente las pruebas AEP, ABR, ASSR, VEMP y OAE en pacientes de todas las edades. Gracias a sus módulos de software especializados, Eclipse puede personalizarse completamente para adaptarse a las necesidades clínicas y al nivel de complejidad diagnóstica de cada centro. El módulo ABRIS permite realizar cribado auditivo automatizado rápido, con resultados claros APTO/NO APTO, formación mínima del operador y alta objetividad, ideal para programas de tamizaje neonatal y poblacional. Por su parte, el sistema ASSR reduce hasta en un 50% los tiempos de prueba, utilizando estímulos CE-Chirp® de banda estrecha y métodos avanzados de detección automática. El módulo EP15 ofrece pruebas ABR neurológicas, de umbral y eABR, con herramientas avanzadas como ponderación bayesiana, cálculos automáticos de ruido residual, SNR y latencias normativas. Para centros que requieren estudios más complejos, el módulo EP25 amplía las capacidades con AEP avanzados (AMLR, ALLR, P300/MMN), ECochG, CM y funciones de investigación.
